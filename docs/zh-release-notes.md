# 中文学习版 1.34.1 发布说明

显示名称：LinguaMiner 中文学习版。计划仓库名：lingua-miner-zh。
基于原项目 v1.34.0，基线提交 `9a5841fc854fca335cc9d3bef8b8f162670c94af`。
本版保留原项目结构与学习操作；修改集中于中文适配、英语字幕导入、错误处理、播放器布局和 Windows 安装。

## 修改内容

- 默认英语学习、简体中文界面及英汉翻译，首次设置请求完成之前也显示中文。
- 提供中文词典、设置、引导、提示、语言名称和错误提示；保留上游语言资源以兼容既有配置。
- 英语单词浮窗保留单词、音标和中文多义释义，隐藏多余解释；原悬停事件及发音、重播、状态、编辑、制卡操作保留。
- 通过原有 StarDict 导入器安装 ECDICT，下载文件校验 SHA-256；使用独立词典标识避免覆盖其他用户词典。
- 使用原 CTranslate2/OPUS 引擎进行英语到简体中文的句子翻译；悬停查词不再等待句子翻译模型。
- 英文文本字幕轨自动提取，并在需要重封装视频前完成；优先完整轨道，避免仅提取强制字幕。
- 有内置英文字幕时不再引导用户重复运行 Whisper；没有字幕时保留外挂字幕和原有识别流程。
- 上传未成功或服务器未返回有效 job_id 时，前端不再轮询 undefined 任务；区分上传、连接与真实任务不存在错误。
- 大视频临时上传文件跟随应用数据目录，避免默认占满系统盘。
- 窄窗口字幕列表改为纵向布局，观察控制栏高度变化，避免字幕随进度拖动时被顶到视频外裁切。
- Windows 双击安装入口准备英语模型、词典、翻译和 small 识别模型；锁文件同步补齐上游声明但遗漏的依赖。
- 资源版本号升级为 1.34.1，避免浏览器继续显示原版缓存。

## 适用范围

- 文本英文字幕可提取；画面内烧录字幕或 PGS/VobSub 图片字幕不可直接提取。
- 原字幕本身的空白时间段正常不显示字幕；本补丁不伪造对白，也不补齐 Whisper 漏识别片段。
- 任务状态仍沿用原项目的进程内存存储：处理中关闭服务器会终止任务；此次修复不宣称支持跨重启恢复尚未完成的任务。
- 已完成导入的会话保存在数据库中，正常重启后可重新打开，也可创建新的导入任务。
- Anki 外部客户端未打开，因此未实测发送卡片到 Anki；相关原项目自动测试通过。
- Windows 为本次实测平台，其他平台的安装尚未按中文版完整验收。
- 首次安装需要访问 GitHub、PyPI 与模型站点；源码包不是包含全部模型的免安装离线整合包。
